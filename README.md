Attendify – Student Attendance Management System

Attendify is a simple and responsive Student Attendance Management System built using HTML, CSS, and JavaScript. It provides an easy-to-use interface for registering students, managing attendance, and viewing attendance statistics.

🚀 Features

- Dashboard: Displays total students, present students, absent students, and attendance percentage.
- Student Management: Register new students with their ID, name, course, and semester.
- Duplicate ID Validation: Prevents registration with an existing student ID.
- Attendance Management: Mark students as Present or Absent.
- Automatic Statistics: Updates dashboard statistics whenever attendance changes.
- Attendance Reports: Displays attendance summaries and a progress bar.
- Responsive Design: Works on desktop, tablet, and mobile screens.

1. Clone this repository:

2. Open the project folder.

3. Open "index.html" in your browser.

4. Start registering students and managing attendance.

No additional installation or dependencies are required.

📸 Project Preview

The application contains four main sections:

1. Dashboard – Overview of attendance statistics.
2. Students – Student registration and student records.
3. Attendance – Mark students as Present or Absent.
4. Reports – Attendance percentage and summary.

⚠️ Current Limitations

- Student records are stored temporarily in JavaScript arrays.
- Data is lost when the page is refreshed.
- No database integration is currently available.
- Attendance records are not stored permanently.
- Authentication and admin login are not implemented.

🔮 Future Improvements

- Integrate Flask as the backend.
- Use SQLite for permanent student data storage.
- Add student login and admin authentication.
- Implement attendance history by date.
- Generate downloadable attendance reports.
- Add search and filter functionality.

🎯 Project Objective

The objective of Attendify is to create a simple digital platform that makes student registration and attendance management easier while reducing the need for manual attendance records.
